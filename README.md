This repository covers advanced Python backend development completed as part of the **ALX Software Engineering Program**, focusing on **Static Type Annotations (`typing` module)**, **Asynchronous Programming (`asyncio`)**, and **Async Comprehensions / Generators**.

---

## Curriculum & Directory Structure

| Module Directory | Topic | Key Concepts & Implementations |
| :--- | :--- | :--- |
| [0x00-python_variable_annotations](./0x00-python_variable_annotations) | Variable Annotations | Python 3 type hints, primitives, complex types (`List`, `Tuple`, `Dict`), `Union`, `Callable`, `Optional`, duck typing, `mypy` |
| [0x01-python_async_function](./0x01-python_async_function) | Async Python Basics | Coroutines, `async`/`await`, concurrent execution via `asyncio.gather`, measuring execution runtime, creating `asyncio.Task` |
| [0x02-python_async_comprehension](./0x02-python_async_comprehension) | Async Comprehensions | Asynchronous generators (`async def`, `yield`), async list comprehensions (`[i async for i in ...]`), runtime benchmarking |
